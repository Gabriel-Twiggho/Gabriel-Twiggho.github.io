# Portfolio contribution guide

Before changing this portfolio, read `DESIGN_SYSTEM.md` in full and follow it as the visual and interaction source of truth.

- Keep the site static: `index.html`, `css/styles.css`, and `js/main.js` are the primary source files.
- Reuse the established design tokens, component patterns, and responsive breakpoints.
- Preserve canonical hash routes and the legacy `project1`–`project4` aliases unless public links are deliberately migrated.
- When changing the UI or navigation, verify desktop and mobile layouts, direct hash links, and browser-console health.
